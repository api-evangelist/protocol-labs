# Protocol Labs

> Protocol Labs is an open-source research and development company founded in 2014 by Juan Benet. It created foundational decentralized web protocols — IPFS, Filecoin, libp2p, and IPLD — and today operates as an innovation network of 750+ startups, funds, accelerators, and open-source projects across web3, AI, robotics, and neurotechnology. Protocol Labs (protocol.ai) is a research and venture organization and does not publish a first-party commercial REST API; its developer surfaces live in separate open-source projects.

## Projects (separate open-source developer surfaces)
- [IPFS](https://ipfs.tech): Content-addressed peer-to-peer hypermedia protocol with HTTP APIs
- [Filecoin](https://filecoin.io): Decentralized storage network with JSON-RPC APIs (Lotus)
- [libp2p](https://libp2p.io): Modular peer-to-peer networking stack
- [IPLD](https://ipld.io): Data model for content-addressed, interoperable protocols
